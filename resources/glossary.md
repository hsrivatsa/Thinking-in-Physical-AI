# Working glossary

[Resources](README.md)

These are concise working definitions for the course shell, to be refined and linked to lessons and sources.

| Term | Working meaning |
|---|---|
| Physical AI | AI-enabled systems that sense, interpret and affect physical environments; the course focuses on physically consequential, feedback-driven behavior. |
| Embodiment | The physical form and capabilities through which a system interacts with its environment. |
| Affordance | An action possibility offered by the relationship between body and environment. |
| State estimation | Inferring relevant world or machine state from observations and models. |
| Partial observability | The system cannot directly observe all relevant state. |
| Feedback control | Using observed behavior to adjust actions toward a target. |
| VLA | Vision-language-action model; a learned approach relating visual inputs and language to action representations. |
| World model | A representation used to predict aspects of how a world state may evolve. |
| Sim-to-real gap | Discrepancy between modeled/simulated behavior and physical-world behavior. |
| Operating envelope | Documented intended conditions of use; terminology and requirements vary by domain. |
| Authority | Permission and responsibility for consequential actions, not mere ability to act. |
| Accepted outcome | Completed work that meets specified acceptance criteria. |
| 4D | Done, Dependable, Desired, Duplicated — a proposed product-readiness lens. |
| Physical MAC/MAP | Companion-book Minimum Product Thinking concepts: Minimum Automated Concept / Minimum Awesome Product; detailed definitions to be developed. |
| Robonomics | Course shorthand for the economics of robotic and intelligent physical work. |
| RaaS | Robotics-as-a-Service, a service-based commercial arrangement whose terms vary. |
| NPI | New Product Introduction; hardware validation/production practices vary by organization and product. |
