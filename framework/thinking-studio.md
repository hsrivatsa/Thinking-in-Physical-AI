# The Physical AI Thinking Studio

[Framework](README.md) · [Thinking journal](../portfolio/thinking-journal.md)

Every module follows the same proposed experiential cycle. The topic is the vehicle; the reasoning competence is the goal.

| Step | Learning activity | Evidence |
|---|---|---|
| 1. Encounter | Start with a concrete physical dilemma | Problem description |
| 2. Predict | Form and explain an initial hypothesis | Prior prediction |
| 3. Understand | Study relevant principles and mechanisms | Mental model |
| 4. Experiment | Use a safe simulation, supplied trace, comparison or scenario | Reproducible observation |
| 5. Challenge | Vary conditions; test failure and alternative explanations | Contrast or held-out case |
| 6. Explain | Connect results to causes and constraints | Revised explanation |
| 7. Decide | Make a bounded decision and explain alternatives | Decision and conditions |
| 8. Reflect | Identify how thinking changed and where uncertainty remains | Journal entry |
| 9. Transfer | Apply the practice to an unfamiliar domain | Transfer response |

No-code does not mean no experimentation. Core labs should include an accessible method to investigate or manipulate evidence. A simulated trace is not proof of hardware behavior. Every published lab must state inputs, variables, instructions, expected limitations, and how to reproduce it.
